# Front-End Developer 
Peran: Sebagai front-end developer saya bertanggungjawab untuk mengembangkan bagian antarmuka pengguna (UI) agar dapat digunakan dengan baik, menarik responsif, dan sesuai dengan kebutuhan pengguna.

Kontribusi: Beberapa kontribusi saya dalam project ini yaitu:
    1. Pengembangan Antarmuka (UI)
        - Membuat tampilan antarmuka menggunakan HTML,CSS, dan Javascript.
        - Mengubah desain atau rancangan tampilan menjadi antarmuka yang dapat digunakan.
    2. Responsive Design
        - Memastikan tampilan dapat menyesuaikan berbagai ukuran layar
        - Menguji tampilan agar tetap nyaman digunakan pada berbagai perangkat
    3. Pengalaman Pengguna (UX)
        - Membuat tampilan yang sederhana, nyaman dan mudah dipahami
    4. Integrasi dengan Back-End
        - Menghubungkan bagian front-end dengan back-end melalui API
        - Menampilkan data dari back-end pada UI dengan benar
    5. Pengujian dan Perbaikan.
