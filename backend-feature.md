# Peran: Back-End Developer

## Nama:
Ayu Nur Lestari

## Peran dan Tanggung Jawab:
Sebagai Back-End Developer dalam Tim Softdev Kelompok 8, tugas dan kontribusi saya meliputi:

1. Membantu merancang dan mengembangkan fungsi backend sesuai kebutuhan proyek.
2. Mengatur struktur dan logika backend agar dapat mendukung fitur yang dikembangkan.
3. Memastikan fungsi backend dapat berjalan dengan baik dan sesuai dengan kebutuhan sistem.
4. Melakukan perubahan dan pengembangan pada bagian backend melalui repository GitHub.
5. Berkoordinasi dengan anggota tim lainnya dalam proses pengembangan proyek.

## Kontribusi Tugas:
Kontribusi saya dalam tugas ini adalah:

1. Membuat branch `feature-ayu` untuk mengerjakan bagian saya.
2. Membuat file `backend-feature.md` sebagai dokumentasi peran dan kontribusi Back-End Developer.
3. Melakukan commit terhadap perubahan pada branch `feature-ayu`.
4. Melakukan push branch ke repository GitHub kelompok.
5. Membuat Pull Request dari branch `feature-ayu` menuju branch `main`.
6. Berkontribusi dalam proses kolaborasi GitHub sesuai workflow yang ditentukan.
